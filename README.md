# A/B-тест: Пуш-уведомления vs Баннеры в SkyLenta

Оценка эффективности нового формата маркетинговых уведомлений. Сравнение конверсии и среднего чека между тестовой (push) и контрольной (баннеры) группами.

## Данные
- 55 605 клиентов, 66 торговых точек, 23 города
- Эксперимент длился 3 месяца

## Методы
- Статистические тесты: t-тест и Манна-Уитни
- Поправка Бонферрони
- Сегментация по городам и торговым точкам

## Инструменты
Python (pandas, numpy, matplotlib, seaborn, scipy), Jupyter Notebook, Excel

## Результаты
- **ARPU:** +162.71 руб. (p = 2.07 × 10⁻¹⁰)
- **Конверсия:** +2.26 п.п. (p = 1.00 × 10⁻⁷)
- 18 точек с положительным эффектом, 3 с отрицательным
